New to this configuration?  Start with [[file:tutorials/getting-started.org][Getting started]]: it installs
it on NixOS or on macOS with Homebrew, in a few commands.  Then [[file:tutorials/first-day.org][A
first day with this configuration]] shows the moves of an ordinary day.

The pages come in four kinds, so that you can find the right one for
what you are doing:

| Kind        | Read it when you want to                   | Directory      |
|-------------+--------------------------------------------+----------------|
| Tutorial    | learn, by doing a guided lesson            | =tutorials/=   |
| How-to      | get a task done, and know what the task is | =how-to/=      |
| Reference   | look up a fact: a key, a command, a name   | =reference/=   |
| Explanation | understand why it is built this way        | =explanation/= |

The configuration itself, with the explanation of each of its parts,
is [[file:../README.org][README.org]] at the root of the repository.

* Tutorials

- [[file:tutorials/getting-started.org][Getting started]]: install the configuration and start it, on NixOS
  or on macOS with Homebrew.
- [[file:tutorials/first-day.org][A first day with this configuration]]: files, search, windows, git
  and tasks, on a practice project.
