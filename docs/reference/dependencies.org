#+TITLE: External dependencies
#+OPTIONS: toc:nil num:nil
#+KEYMAPS: prog-mode-map clojure-mode-map

What the configuration needs outside its own files.  The programs and
fonts are listed in [[file:../../nix/programs.nix][nix/programs.nix]], each with what uses it: the
configuration's flake installs them, and without Nix you install the
same ones by other means, since each name there is a nixpkgs
attribute.  [[file:../tutorials/getting-started.org][Getting started]] installs them on NixOS and macOS.  A
missing optional program disables only its feature: the language
server of a language, for example, does not start.

* Emacs

| Need                | Version | Why                                                                           |
|---------------------+---------+-------------------------------------------------------------------------------|
| GNU Emacs, minimum  |    29.1 | lsp-mode, =enable-theme-functions=                                            |
| GNU Emacs, advised  |    30.1 | ships which-key and editorconfig; the tests need it (=handler-bind=)          |
| GNU Emacs, tested   |    31.1 | the build this configuration is tested with: pgtk on NixOS (=emacs-pgtk=)     |
| Native compilation  |         | faster packages; Emacs built with libgccjit                                   |
| Tree-sitter support |         | the =-ts-mode= major modes, folding; grammars go to =~/.emacs.d/tree-sitter/= |

On Emacs 30, Java indents by 4 until JDTLS formats the file.  The
setup, [[file:../../nix/setup.sh][nix/setup.sh]], installs the tree-sitter grammars: it links
nixpkgs's when the flake runs it, and otherwise has Emacs compile
them, which needs git and a C compiler.

* The lists of nix/programs.nix

| List     | Holds                                                                                                                                     | Installed by                              |
|----------+-------------------------------------------------------------------------------------------------------------------------------------------+-------------------------------------------|
| =tests=  | what the tests use: git, ripgrep, the Python, Clojure, Java, shell, OpenTofu and Markdown language servers, the spell checker's libraries | the flake's =programs=, the CI, the trial |
| =others= | every other program the configuration calls: the other language servers, formatters, project tools, dictionaries                          | the flake's =programs=                    |
| =fonts=  | the Nerd Font of the default face and its icons, Noto Sans CJK                                                                            | the flake's =programs=, the trial         |

A comment in that file names the programs the flake leaves
out: zig, which builds gterm's module, TeX Live, a container engine,
a music player and Starship.

* Fonts

| Font                   | Used for                                                                                                                    | nixpkgs               |
|------------------------+-----------------------------------------------------------------------------------------------------------------------------+-----------------------|
| Iosevka Nerd Font Mono | the default face; else the first installed of Iosevka Term, Iosevka, JetBrains Mono, then DejaVu Sans Mono (Menlo on macOS) | =nerd-fonts.iosevka=  |
| Noto Sans CJK          | Chinese, Japanese and Korean text                                                                                           | =noto-fonts-cjk-sans= |
| Garamond               | reading EPUB books (nov); the family must be named Garamond                                                                 | none                  |

The icons of Dirvish, the mode line and completion come from the Nerd
Font; =M-x nerd-icons-install-fonts= installs the symbols alone.  On
macOS, a font installed by Nix only reaches Emacs once the system has
it, as Homebrew's casks or Font Book install it.

* Inside each project

Some tools belong to the projects that use them, not to the machine:
=debugpy=, =pytest= and =ptw= in each Python project, found through
its environment.
