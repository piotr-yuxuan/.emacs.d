#+TITLE: External dependencies
#+OPTIONS: toc:nil num:nil
#+KEYMAPS: prog-mode-map clojure-mode-map

Every program and font the configuration uses outside Emacs, found on
=PATH=.  The last column is the nixpkgs attribute, for Home Manager's
=home.packages= or NixOS's =environment.systemPackages=; [[file:../tutorials/getting-started.org][Getting
started]] installs them on NixOS and macOS.  A missing optional program
disables only its feature: the language server of a language, for
example, does not start.

* Emacs

| Need                | Version | Why                                                                           |
|---------------------+---------+-------------------------------------------------------------------------------|
| GNU Emacs, minimum  |    29.1 | lsp-mode, =enable-theme-functions=                                            |
| GNU Emacs, advised  |    30.1 | ships which-key and editorconfig; the tests need it (=handler-bind=)          |
| GNU Emacs, tested   |    31.1 | the build this configuration is tested with: pgtk on NixOS (=emacs-pgtk=)     |
| Native compilation  |         | faster packages; Emacs built with libgccjit                                   |
| Tree-sitter support |         | the =-ts-mode= major modes, folding; grammars go to =~/.emacs.d/tree-sitter/= |

On Emacs 30, Java indents by 4 until JDTLS formats the file.  Install
the tree-sitter grammars once with =M-x treesit-auto-install-all=,
which needs git and a C compiler.
