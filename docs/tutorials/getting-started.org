#+TITLE: Getting started
#+OPTIONS: toc:nil num:nil

This lesson takes you from nothing to a working Emacs with this
configuration, on NixOS or on macOS with Homebrew.  You need no
experience with Emacs.  You type a dozen commands; the rest is
waiting while Emacs downloads its packages, about ten minutes.

Each step gives the commands for NixOS, then for macOS.  Run the
commands in a terminal.

* 1. Install Emacs, git and a C compiler

Emacs is the editor; this configuration needs version 30 or later.
git downloads the configuration and its packages.  The C compiler
builds the small grammars that Emacs uses to colour and fold code.

** On NixOS

Add the three packages to =/etc/nixos/configuration.nix=:

#+BEGIN_SRC nix :beginner nixos
environment.systemPackages = with pkgs; [ emacs git gcc ];
#+END_SRC

Then apply the change:

#+BEGIN_SRC sh :beginner nixos
sudo nixos-rebuild switch
#+END_SRC

** On macOS

Install Homebrew from [[https://brew.sh][brew.sh]] if you do not have it yet.  It also
installs Apple's command line tools, which bring git and a C compiler.

Emacs reads the programs it can use from your login shell, so that
shell must know Homebrew.  On a Mac with Apple silicon, Homebrew's
installer prints how to do it at the end; this command does it if that
was skipped, and does nothing otherwise.  On an Intel Mac, Homebrew
lives in =/usr/local=, which the shell knows already, and the command
does nothing either:

#+BEGIN_SRC sh :beginner macos
if [ -x /opt/homebrew/bin/brew ]; then
  grep -qs 'brew shellenv' ~/.zprofile ||
    echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
  eval "$(/opt/homebrew/bin/brew shellenv)"
fi
#+END_SRC

Then install Emacs, and GNU's basic tools, whose =ls= the file manager
of Emacs needs to list a directory:

#+BEGIN_SRC sh :beginner macos
brew install --cask emacs-app
brew install coreutils
#+END_SRC

** Check

Open a new terminal and run:

#+BEGIN_SRC sh :beginner both
emacs --version
#+END_SRC

The first line should say GNU Emacs 30 or later.

* 2. Get the configuration

Emacs reads its configuration from the directory =~/.emacs.d=.  Rather
than putting the repository there, keep it with your other projects
and make =~/.emacs.d= a link to it.  You then work on the
configuration like any other repository, and going back to your old
setup only means removing the link.

If you used Emacs before, move your old configuration aside, since
Emacs would read =~/.emacs= or =~/.emacs.el= before this one.  This
command renames whichever of them exists, and changes nothing on a
machine that has none:

#+BEGIN_SRC sh :beginner both
for old in ~/.emacs ~/.emacs.el ~/.emacs.d; do
  if [ -e "$old" ] || [ -L "$old" ]; then mv "$old" "$old.before"; fi
done
#+END_SRC

Then clone the repository and make the link:

#+BEGIN_SRC sh :beginner both
git clone https://github.com/piotr-yuxuan/.emacs.d.git ~/emacs-config
ln -s ~/emacs-config ~/.emacs.d
#+END_SRC

To go back one day, remove the link with =rm ~/.emacs.d= (the clone
stays), and rename your old files without their =.before=.

* 3. Start Emacs

- On NixOS, run =emacs= in a terminal, or pick Emacs in your
  applications menu.
- On macOS, open Emacs from Applications or Launchpad.  The first
  time, macOS asks whether to open an application downloaded from the
  internet: choose Open.

The first start downloads and builds about 150 packages.  The bottom
line of the window shows "Cloning" and "Building" messages for five to
ten minutes; let it work.  If it stops with an error about
=git clone=, a download failed: quit and start Emacs again, and it
carries on where it stopped.  Then you see the dashboard: the Emacs logo
and "Welcome to Emacs", in a dark or light theme that follows your
system's.

A few minutes later, Emacs builds the grammars in the background.  The
bottom line then says "Grammars:" and how many it built; the few that
fail are harmless.  Until then a Python or YAML file opens without colours: open
it again once the grammars are there.

Quit with =C-x C-c=: hold Control, press x, then c.  The next start
takes a second or two.

You now have a working Emacs.  [[file:first-day.org][A first day with this configuration]]
teaches the moves of an ordinary day; the steps below can wait.

* 4. Add the programs for what you do

Everything above works with Emacs, git and the compiler alone.  Some
features call other programs; without them, the feature stays off and
nothing breaks.  Add the groups you want:

| Group           | What you get                                     | NixOS packages         | Homebrew                 |
|-----------------+--------------------------------------------------+------------------------+--------------------------|
| Search          | search a whole project, find files by name       | =ripgrep fd fzf=       | =ripgrep fd fzf=         |
| Diffs           | readable diffs in Magit, the git interface       | =delta=                | =git-delta=              |
| Spell checking  | misspelt words underlined as you type            | see below              | =enchant pkgconf=        |
| Font and icons  | the Iosevka font, and the icons of file lists    | =nerd-fonts.iosevka=   | =font-iosevka-nerd-font= |

On NixOS, extend the list of step 1 and add the font, then run
=sudo nixos-rebuild switch= again:

#+BEGIN_SRC nix :beginner nixos
environment.systemPackages = with pkgs; [ emacs git gcc ripgrep fd fzf delta ];
fonts.packages = [ pkgs.nerd-fonts.iosevka ];
#+END_SRC

Spell checking on NixOS needs the libraries of a spell checker where
the compiler finds them: [[file:../how-to/install-with-nix.org][Install everything with Nix]] sets that up.

On macOS:

#+BEGIN_SRC sh :beginner macos
brew install ripgrep fd fzf git-delta enchant pkgconf
brew install --cask font-iosevka-nerd-font
#+END_SRC

Restart Emacs afterwards: it looks for programs when it starts.

For a programming language, its guide says what to add: [[file:../how-to/python.org][Python]],
[[file:../how-to/clojure.org][Clojure]].  [[file:../reference/dependencies.org][External dependencies]] lists every program the
configuration can use.

* 5. Tell it who you are

Settings that belong to one machine, such as your name, go in
=~/.emacs.d/local.el=, which git ignores.  Start from the example:

#+BEGIN_SRC sh :beginner both
cp ~/.emacs.d/local.el.example ~/.emacs.d/local.el
#+END_SRC

Open it, in Emacs with =C-x C-f= or in any editor, and set your name
and email address.  [[file:../reference/local-el.org][The local.el reference]] explains the other
settings; leave them as they are for now.
